Figure 8
Failure Under Realistic Load — Mixed Workload During Election
Writes + reads + aggregations running simultaneously when primary was killed
17
Write Failures
Writes must go to primary. No primary = all writes fail until election completes (62s).
3
Read Failures
Reads routed to secondaries via replica set URI. Recovered within seconds. Secondaries stay up during election.
2
Aggregation Failures
Aggregations routed to secondaries. Recovered within seconds. Same behavior as reads.

Engineering implication: design separate retry strategies per operation type. Read failures → retry immediately. Write failures → retry for the full election duration (67 seconds on this infrastructure).
